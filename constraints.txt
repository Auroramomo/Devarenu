# Die vollstaendige Aufloesung, so wie sie fuer Python 3.13 herauskam.
#
# requirements.txt nennt die zwoelf Pakete, die Devarenu wirklich
# braucht. Was die mitziehen -- vierzig weitere -- stand bisher nirgends,
# und zwei an verschiedenen Tagen gebaute Sticks konnten sich darin
# unterscheiden. Diese Datei nagelt auch das fest.
#
# Gedacht als Randbedingung, nicht als Einkaufsliste: pip installiert
# nichts davon allein, sondern nur, was requirements.txt anfordert -- und
# dann genau in dieser Fassung. Deshalb schadet ein Eintrag hier nicht,
# der auf einem anderen Weg gar nicht gebraucht wird.
#
#   einrichten.sh    pip install -c constraints.txt -r requirements.txt
#   stick_bauen.sh   pip download -c constraints.txt -r requirements.txt
#
# Neu erzeugen nach einer Aenderung an requirements.txt:
#   ./stick_bauen.sh --nur-constraints
#
# Nicht von Hand pflegen. Torch fehlt auch hier, es hat einen eigenen
# Index und eine eigene CUDA-Fassung.
